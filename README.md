# new_repo_tuple

Repositório de teste das pessoas sintéticas do Tuple.

## O que é
Um projeto mínimo para exercitar agentes: ler este README, sugerir melhorias, criar arquivos e abrir pull requests.

## Como contribuir
1. Crie uma branch a partir da `main`.
2. Faça a mudança e abra um PR.

## Pendências conhecidas
- Não há testes automatizados.
- Não há licença definida.
